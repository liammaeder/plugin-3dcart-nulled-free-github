3dcart plugin for WordPress.

== Description ==

3dcart brings a full set of features to your WordPress site. Lightweight,
regularly updated and compatible with all modern themes and page builders.

== Installation ==

1. In your admin panel, go to Plugins -> Add New and click Upload Plugin.
2. Browse for 3dcart.zip and click Install Now.
3. Click Activate.
